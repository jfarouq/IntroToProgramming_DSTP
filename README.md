# Welcome

This repo supports an introductory web programming course for 9th graders (ages 14–15).

For most students, this course is their first real programming experience. Over the course of it, they write code in an IDE, push changes to a remote server, use Linux, query a MySQL database, get a basic introduction to git, and build a working web application with PHP, HTML, CSS, and Bootstrap.

The templates here give students a starting point for their own web apps.

The code has known security and performance shortcomings. That is intentional. Students learn the core concepts first in simplified form, and then we move toward more secure, efficient, and conventional practices. The comments are deliberately heavy so beginners can follow what each part does.

Requirements: a LAMP stack (Linux, Apache, MySQL, PHP) and a database with a specific table structure. Run store_setup.php to configure the store. Our hosting is on Linode.
